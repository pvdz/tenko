# Tenko parser test case

- Path: tests/testcases/classes/string_methods/async_string_method_id.md

> :: classes : string methods
>
> ::> async string method id
>
> This was caught by the fuzzer. ZeParser threw but node/v8 did not, and node/v8 is right here.
>
> Async methods are a restricted production (`AsyncMethod :: async [no LineTerminator here] ClassElementName ...`)
> so the newline does rule out the async-method reading. But in a class body that is not the only reading left:
> `async` is then simply a `FieldDefinition` terminated by ASI, followed by the string keyed method `'y'(){}`
> and the getter `.2(){}` (`.2` being the numeric key `0.2`). In an *object* literal there is no field production,
> which is why the twin `({async\n'y'(){}})` really is an error.
